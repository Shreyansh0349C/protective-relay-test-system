# RELAYLAB X — Protective Relay Test System (Phase 1)

Professional desktop software prototype for protective relay testing.

- **GUI:** PySide6
- **Plotting:** PyQtGraph
- **Simulation:** NumPy
- **Communication:** PySerial / Mock STM32H753
